# Sylph 首页与管理界面统一设计修改方案

## 1. 方案状态与目标

本文件已按当前工作树实施，真实浏览器视觉与业务点击验收仍待可访问环境完成。以当前工作树的首页视觉与交互为基准，统一管理界面的材质、层级、尺寸、按压反馈和明暗模式。当前首页基准包括暖灰玻璃搜索框、96×42px 文字书签、1px 渐隐分类线、书签整体凹陷按压，以及右下角扁圆玻璃操作区。

目标是让管理界面看起来属于同一个产品，同时让密集编辑任务保持清晰、稳定、易操作。保留现有 Node.js 与原生前端、数据结构、接口、搜索触发符、隐私语义、WebDAV 和书签跳转方式。

## 2. 设计原则

1. **材质有主次。** 搜索框、主弹层和二级对话框承担玻璃层次；表单行与列表保持克制，避免每一项都浮起。
2. **按钮靠表面与边缘表现厚度。** 浅色模式使用细微面内渐变、内缘高光和压入状态，避免在按钮外侧堆叠投影。深色模式保留现有低照度光感。
3. **按压整体下沉。** 书签现有的整体缩入、表面转暗、内侧加深及短暂停留作为触感基准。管理界面的普通按钮使用幅度更小的同类反馈；破坏性操作强调清晰确认。
4. **分割线保持纤细。** 分类及管理区必要的分隔使用单条 1 CSS px 渐隐线。列表行优先靠间距分组，避免密集边框。
5. **颜色服务状态。** 暖灰、陶土和深棕是主色系。成功、错误、警告只在状态文字与小面积标记中出现，不铺满大色块。
6. **性能与隐私保持原有边界。** 不增加远程字体、外站图标、图片或全页持续动画；管理信息仍在原有认证与权限范围内。

## 3. 基础规范

| 对象 | 浅色 | 深色 | 建议规格 |
| --- | --- | --- | --- |
| 页面背景 | 现有暖矿物灰 `#efede8` | 现有深棕灰 `#211f1c` | 保持当前色值 |
| 强调色 | 陶土 `#945e4a` | 暖铜 `#c28d70` | 只用于主动作、选中和焦点 |
| 主玻璃层 | 现有 `--glass-strong`，保留轻微背景模糊 | 现有深色玻璃变量 | 主弹层和二级对话框使用 |
| 普通编辑面 | 暖灰白低对比表面 | 深棕灰低对比表面 | 行与输入比玻璃层更实 |
| 分割线 | 暖灰褐透明度渐隐 | 暖灰白透明度渐隐 | 1 CSS px，无叠层阴影 |
| 普通按钮 | 面内渐变、细内缘、轻压入 | 延续现有深色按键光感 | 桌面高 34 至 38px |
| 紧凑按钮 | 同材质，减小留白 | 同左 | 桌面高 30 至 32px |
| 输入与选择 | 浅色实体内凹面 | 深色实体内凹面 | 桌面高约 38px，圆角 8px |
| 移动触控 | 保持表面比例，扩大可点区域 | 同左 | 目标触控区域约 44px |

现有书签尺寸、搜索框比例和右下角操作区尺寸保持基准。管理界面圆角建立三级关系：主弹层约 16px，内部面板约 10 至 12px，输入和普通按钮约 8px。只有右下角操作区继续使用胶囊形。

### 交互时间

| 状态 | 规则 |
| --- | --- |
| 悬停 | 80 至 120ms 内完成边缘与表面变化，位移不超过 1px |
| 按下 | 约 25 至 45ms 进入压入状态，整颗按钮与文字同步 |
| 松开 | 书签沿用当前约 135ms 的可见停留；表单按钮回位约 100 至 140ms |
| 聚焦 | 显示清楚的键盘轮廓，不依赖悬停或颜色变化 |
| 加载 | 保留按钮宽度，原位显示动作进度并禁止重复提交 |
| 减少动态效果 | 保留状态差异，取消位移、缩放与跟随光 |

## 4. 首页需要保持和补齐的部分

首页继续使用现有搜索、收藏分类、书签及操作区。实施时核对书签按压在鼠标、触屏和键盘激活后的状态一致性，并检查新页面打开前后的反馈时序。浅色书签继续使用面内材质，不恢复显眼的外围投影。深色维持原有环境光与按钮反射。分类细线保持目前的单线渐隐处理。

搜索模式、搜索引擎、收藏检索、分享输入和右下角操作入口只做状态规范化。不得改变 `/`、`//`、分享触发符、链接目标或数据查询结果。

## 5. 管理界面完整范围

| 区域 | 现有功能 | 统一设计要求 |
| --- | --- | --- |
| 管理入口与主弹层 | 密码验证、标题、保存状态、取消与保存 | 采用当前玻璃材质；标题与动作对齐；保存状态固定位置，避免文案变化推动按钮 |
| 界面设置 | 主题、默认引擎、隐私开关 | 统一标签基线、选择器高度与聚焦状态；开关呈现明确的开闭、聚焦和禁用状态 |
| 收藏总览 | 数量、导入、导出、添加、管理 | 统计信息降噪；四个动作按频次分级，按钮使用同一材质与按压规则 |
| 搜索引擎编辑器 | 名称、URL、添加、删除 | 紧凑编辑行；输入与小按钮对齐；删除确认及至少保留一个的提示放入统一反馈系统 |
| 书签分类编辑器 | 分类名称、数量、展开、书签、增删、拖动 | 分类行和书签行使用统一的低对比实体面；清楚区分拖动、展开、删除与编辑状态；添加入口改成精致的次级按钮 |
| 收藏管理器 | 分类树、搜索、批量选择、拖动、编辑、删除、分页 | 左侧树和右侧列表共用排版、分隔和选中样式；当前分类、拖放目标、已选条目须一眼可辨 |
| 收藏添加与编辑 | 标题、URL、描述、分类、标签、隐私、保存 | 二级玻璃对话框；字段标签、必填信息、错误文字与保存状态统一；隐私开关保持明确语义 |
| WebDAV 配置 | 启用、地址、账号、密码、路径、保存、测试、备份 | 敏感字段与普通输入同一尺寸；密码占位不得泄露值；连接与备份状态使用文字和小标记表达 |
| 备份列表与恢复 | 列表、删除、恢复范围、进度、结果 | 二级对话框与主弹层同材质；恢复范围有明确选中态；破坏性动作有独立确认与忙碌状态 |
| 密码修改与登录确认 | 管理密码、默认密码提醒、修改密码 | 纳入统一对话框，不再跳出浏览器原生输入框；密码字段和错误提示完整呈现 |
| 退出与放弃更改 | 登出、未保存修改确认 | 退出入口保持低强调；放弃、保存和继续编辑在同一视觉体系内区分 |

### 当前风格断点的处理

管理界面目前同时存在玻璃主弹层、旧式实线卡片、虚线全宽添加按钮、不同高度和圆角的输入控件、emoji 分类图标及浏览器原生 `prompt`、`confirm`、`alert`。实施时需要逐项替换。分类树中的 emoji 改为简洁的文字或本地矢量符号，避免引入新的外部图标请求。主弹层完成后，应逐一检查所有动态生成的二级对话框和消息状态。

## 6. 管理界面的布局与状态

### 桌面

主弹层保持当前约 900px 的宽度上限，内部改为清楚的标题区、滚动内容区和稳定动作区。信息密集处使用行距与渐隐线组织层级，不叠放多个玻璃卡片。收藏管理器保留分类树与列表的双栏结构；左栏不超过约 220px，右栏优先保证标题和 URL 可读。批量操作栏在列表上方稳定占位，避免勾选后整页跳动。

### 窄屏

主弹层沿用全屏方案，固定标题与保存动作，内容单独滚动。收藏管理器将分类树压缩为可换行的分类选择区，列表单列显示；每项的编辑、删除与多选保持足够触控面积。添加与编辑收藏、备份恢复沿用底部面板，但顶缘圆角、留白、背景模糊、按钮材质与主弹层一致。输入字号至少 16px，以防手机浏览器聚焦时自动放大。

### 必须覆盖的状态

默认、悬停、按下、键盘聚焦、选中、展开、拖动、可放置、禁用、加载、空结果、成功、错误和未保存修改。成功与错误应同时有文字说明；删除、恢复、导入等不可逆动作需要清楚的确认内容。对话框打开时焦点进入，关闭后返回触发点；Esc 和背景关闭遵循现有未保存修改保护。

## 7. 原生弹窗与交互一致性

当前管理流程多处使用浏览器原生输入、确认和警告弹窗。它们无法沿用 Sylph 的材质与状态规范。实施时建立一个小型的站内对话框组件，分别提供输入、确认和结果三类模板，并逐步接入以下流程：

1. 管理密码验证、默认密码提醒和密码修改。
2. 放弃未保存修改、分类合并或删除、收藏批量移动或删除。
3. WebDAV 备份删除、恢复确认与结果提示。
4. 收藏导入、导出、表单校验及保存失败。
5. 首页分享流程中仍存在的原生弹窗，作为全产品统一的最后检查项。

组件必须保留原有权限校验、确认后操作顺序与错误处理。密码和备份路径不得进入持久化的界面日志；保存失败时仍保留用户已输入的内容。

## 8. 实施顺序

1. **建立设计变量。** 在 `public/styles.css` 整理明暗主题、材质、圆角、边缘、按压和状态变量；减少文件末尾继续堆叠覆盖规则。形成按钮、输入、弹层、细线四类共用规则。
2. **完成主弹层与基本表单。** 修改 `public/index.html` 和管理面板相关样式，统一标题、保存状态、按钮、选择器、开关及章节节奏。
3. **完成编辑器与收藏管理器。** 调整 `public/app.js` 动态模板和相应 CSS，覆盖分类树、书签行、批量选择、拖放、分页及空状态。
4. **完成 WebDAV 与二级对话框。** 统一连接状态、备份列表、恢复选项、添加和编辑收藏的材质及移动端底部面板。
5. **替换原生弹窗。** 建立站内对话框和焦点管理，逐个迁移管理及分享流程。每迁移一处核对确认语义与失败恢复。
6. **验收与收束。** 清理失效的旧样式覆盖，核对服务工作线程的资源更新，再做明暗、桌面、移动端和实际业务流程验收。

## 9. 验收清单

- 桌面 1440px 与 1024px，手机 390px 与 320px，分别检查浅色、深色及系统跟随。
- 首页书签、管理按钮、保存、取消、删除、添加、分类选择、拖放目标和恢复确认均有完整状态。当前焦点可辨，文本与背景有足够对比。
- 主弹层、收藏管理器、添加和编辑收藏、WebDAV 备份列表、恢复范围、密码流程及原生弹窗替代流程均完成视觉核对。
- 搜索、`/` 与 `//` 收藏检索、书签跳转、保存与放弃、导入导出、隐私字段、批量操作、WebDAV 测试及恢复路径按原逻辑运行。
- 减少动态效果、减少透明效果、无 `backdrop-filter` 浏览器及触屏设备均有可用样式。
- 自动测试与语法检查通过。浏览器视觉验收应依据实际页面和真实状态完成；仿真页只用于审定视觉方向。

## 10. 范围与交付边界

本方案已在工作树实施管理界面改动，保留了此前尚未提交的首页样式与交互修改，并提供可查看的管理界面仿真。当前尚未发布版本；真实页面视觉与业务点击仍待浏览器环境验收。

## 11. 全站补充实施

按用户对范围的校正，分享接收页已采用同系配色。首页搜索结果、分享结果和说明窗口保留 `sylph-depressed-bookmarks.html` 所嵌入的原始生产样式，避免后续覆盖改变搜索框、书签和操作区。首页现有书签大小、按压时序、搜索框比例和深色环境光继续作为基准。真实浏览器中的明暗、移动端及业务点击仍待验收。

## 12. 按钮按压反馈校正

此前将书签的 135ms 松手保持扩展到所有按钮，偏离了已确认仿真。该扩展已撤回。书签继续使用原版整颗下沉和 135ms 保持；搜索框与其他按钮沿用原版各自的材质和即时状态。预览直接复制已确认仿真，不再用近似的手写 `.sap-*` 首页代替。
