# 本地优先个人导航与可选口令同步方案

日期：2026-10-17。修订：第 6 版。状态：设计方案，尚未实现或完成验收。

本文替代此前完整多账号方案。当前代码事实仍以架构文档及实际实现为准。本文中的额度和时延为首版设计默认值，需通过测试验证。

## 1. 目标与边界

所有人共用根路径 `/`。首次访问显示部署者定义的公开首页，用户可直接修改自己的导航并保存在浏览器。无需账号、同步口令或网络写入即可持续使用。跨设备需求通过可选口令同步满足。

部署者保留独立管理员认证、默认首页编辑、收藏库及其检索、私人模块和 WebDAV。所有访问者均可自定义个人搜索引擎，保存于自己的本地配置并按需同步。管理员登录一次即可读取和保存服务端管理员配置，并在其他已登录设备同步，无需普通同步口令。普通空间凭据没有管理员权限。普通空间不增加后台私人采集任务。

首版不实现账号注册、用户名、邮箱、密码找回、角色体系、普通用户 WebDAV、私人模块多租户化或跨用户私人订阅共享。邀请码只控制新建云端空间，不承担用户身份识别。

## 2. 术语与数据归属

| 对象 | 归属与作用 |
| --- | --- |
| 默认首页 | 独立管理、存储及发布的公开模板，仅供普通首次访问和重置使用 |
| 管理员配置 | 服务端保存的管理员个人导航、引擎及模块配置，所有正常管理员会话读取同一份数据，与默认首页独立 |
| 本地配置 | 当前浏览器保存的个人导航，是日常编辑的直接目标 |
| 云端空间 | 同步口令对应的一份配置，支持多个设备连接 |
| 同步连接 | 当前浏览器连接某个云端空间的状态及凭据 |
| 管理员会话 | 进入管理员首页、同步管理员配置及访问管理和私人接口的凭据 |
| 模块策略 | 管理员发布的公开模块可用性，普通配置不能覆盖 |

同一浏览器配置文件、同一站点共用一份普通本地配置和普通同步连接；多标签页协调，首版不支持每标签页连接不同口令。不同浏览器配置文件可使用不同空间。

### 首页配置上下文

| 当前身份状态 | 首页使用的数据 | 保存和同步方式 |
| --- | --- | --- |
| 未登录管理员，未连接口令 | 普通本地配置 | 仅本地保存 |
| 未登录管理员，已连接口令 | 普通本地配置及对应云端空间 | 自动口令同步 |
| 已登录正常管理员 | 服务端管理员导航及模块 | 管理员会话直接保存和跨设备更新 |
| 仅持有改密凭据 | 普通本地配置及改密界面 | 不获得管理员配置或私人数据 |

管理员登录后自动切换管理员首页，切换前的普通本地配置、连接及待上传修改保存在独立命名空间，暂停其全部同步调度。管理员界面显示“管理员首页”，不要求设置或填写普通同步口令；登录本身不把任何普通配置复制到管理员配置。

管理员首页展示管理员导航、管理员选用的公开模块和私人模块，使用同一份服务端管理员模块布局，可按现有布局能力共同排版。公开或私人分类决定对外授权，不能通过拖动改变。管理员模块开关、布局及私人数据不进入普通存储、普通导出或普通云同步。

管理员个人导航、引擎、主题和模块布局保存后只同步管理员自己的配置，不影响默认首页。默认首页通过“站点管理 → 默认首页”独立编辑、预览和发布，使用独立草稿、版本及保存接口；只有明确点击“发布默认首页”才更新匿名模板。模板只允许普通配置 schema 和已开放公开模块，不包含管理员私人模块、收藏或凭据。首版不提供个人导航自动发布、双向关联或一键复制到默认首页。站点授权、邀请码和安全设置使用各自管理表单。

## 3. 功能矩阵

| 功能 | 普通访问者 | 管理员 | 普通云同步范围 |
| --- | --- | --- | --- |
| 导航分类、链接、排序和布局 | 自由配置本地数据 | 个人导航跨设备同步；默认首页单独编辑发布 | 包含普通个人配置 |
| 主题、显示偏好 | 可配置 | 个人设置通过会话跨设备同步；默认模板独立设置 | 包含普通个人配置 |
| 搜索引擎 | 可新增、编辑、删除及选择个人引擎 | 个人引擎直接同步；默认模板引擎独立设置 | 普通个人引擎定义、排序及当前选择 |
| 公开模块 | 开放后按需启用 | 决定对外开放范围 | 开关、布局和允许的非敏感偏好 |
| 微博热搜 | 开放后使用共享榜单 | 可使用 | 仅偏好，不含榜单数据 |
| 文本分享 | 保留现有匿名流程 | 同样可用 | 不含分享内容及历史 |
| 收藏夹管理及导入导出 | 不提供 | 专用 | 不包含 |
| 收藏库检索，含原私密及非私密条目 | 不提供 | 专用 | 不包含收藏库 |
| 备忘录、主机监控、Special Line | 不提供 | 专用 | 不包含 |
| WebDAV 配置、备份与恢复 | 不提供 | 专用 | 不包含 |
| 默认首页、实例设置及同步空间管理 | 不提供 | 专用 | 不包含 |

个人导航中的链接与管理员收藏库保持独立。用户编辑链接不能修改管理员收藏。收藏库全部条目及其检索、计数、分类、导出和索引仅向管理员提供，原非私密标记不再授予匿名读取权限。匿名和普通空间不提供收藏检索入口，不下载收藏数据或构建收藏索引；既有公开收藏接口停止对其返回数据，直接访问返回 401 或 403。公开默认导航中由管理员明确发布的链接继续可见，不因此开放收藏库。

## 4. 首页与本地保存

1. 启动先读取普通本地配置并并行检查管理员会话。会话未确认前仅渲染普通公开配置，不加载管理员数据；可用管理员会话确认后自动切换管理员首页。检查完成前不启动普通或管理员自动同步；用户若已开始本地编辑，身份切换前先处理该草稿。检查失败显示“无法确认管理员登录”，允许普通本地保存但保持网络同步暂停，不把失败当作明确退出；用户主动选择“仅使用本地导航”可继续离线操作，网络恢复后重新确认身份。
2. 没有本地配置时获取默认首页，建立本地副本。首次离线且没有任何副本时展示可重试状态，不伪装加载成功。
3. 使用 IndexedDB 保存配置、版本、待同步修改及同步连接，不把个人数据放进 Service Worker 静态资源缓存。
4. 个人配置的有效修改立即持久化。输入中的未完成文本及尚未确认的对话框不进入同步。导航结构编辑完成有效操作即可保存，提供撤销上一操作能力，离开页面不依赖最后一次网络提交。
5. 刷新、关闭浏览器、管理员登录或退出、静态资源缓存升级不清空普通个人配置。管理员配置仅在在线验证会话后读取，不持久缓存到普通 IndexedDB；离线启动可使用保留的普通配置，不展示收藏和私人模块。存储失败必须提示“未能保存到本机”，不得显示已保存。
6. 管理员更新默认首页及其默认引擎不覆盖已有本地配置。模块开放策略以服务端当前结果为准；个人搜索引擎定义、排序和选择由本地配置管理，并进入普通云同步。
7. 用户删除当前引擎时选择剩余列表第一项；最后一个引擎不可删除，除非先新增替代项。恢复或导入时当前引擎 ID 无效则回退到已校验列表第一项，空引擎列表拒绝导入；未知模块偏好不执行、不加载脚本。
8. 本地数据丢失后，无同步副本时无法恢复；明确说明清除站点数据、浏览器回收及隐私浏览的影响。提供本地 JSON 导出与校验后导入，范围与普通同步一致，不新增收藏夹管理能力。

### 重置默认配置

此操作仅作用于普通上下文。管理员个人上下文不显示“重置为默认配置”，个人导航与模板分别编辑；管理员可取消各自未保存编辑，重置站点数据不属于首版功能。

获取管理员当前公开默认值，确认后原子替换本地配置；获取失败不修改现有数据。重置不改变同步连接。同步开启时，确认文案说明重置将上传并影响同一空间其他设备。重置保持单调递增的本地修订号，不清空版本保护。

## 5. 普通口令同步生命周期

| 状态或操作 | 本地配置 | 同步连接 | 云端 |
| --- | --- | --- | --- |
| 仅本地 | 持续保存 | 无 | 不访问个人空间 |
| 已连接 | 持续保存 | 持久保存 | 自动读写 |
| 离线或失败 | 保存并标记待上传 | 保留 | 恢复网络后协调 |
| 配置冲突 | 保留本地及拉取的云端版本 | 保留，暂停上传 | 等待选择 |
| 停止同步 | 保留 | 删除全部凭据及待上传任务 | 保留 |
| 删除云端空间 | 保留 | 删除 | 删除配置并撤销全部设备凭据 |

本节的停止、删除、令牌和额度只适用于普通空间，不撤销管理员会话或删除管理员配置。管理员上下文隐藏普通同步设置，并提示“已通过管理员登录同步，无需同步口令”。

同步状态展示“仅保存在本机”“同步中”“已同步”“离线，待同步”“同步失败”“存在配置冲突”，并展示最近成功时间。只有服务端确认保存且本地没有后续修改时才显示已同步。

### 开启同步

- 用户自设口令，长度 6 至 128 个 Unicode 码点，区分大小写，不静默去除空格或进行字符归一化；全空白拒绝。首次设置要求再次输入确认。不强制随机生成或复杂度。
- 提示知道口令即可读写和删除对应空间，口令遗失无法找回。简单口令及同口令共用空间的风险由用户接受。
- 先检查空间是否存在。不存在时，明确确认“用当前本地配置创建”；存在时先取得配置并显示更新时间和条目数量，选择“使用云端配置”或“以本地配置替换云端”。两个方向均保留被替换配置的本地恢复副本。
- 云端替换必须基于检查时版本，期间有变化则重新提示，禁止覆盖最新内容。
- 新建空间使用有效邀请码；已有空间连接无需邀请码。服务端原子检查口令对应空间是否存在，竞争创建返回已存在，不能抢写。
- 停止后重新连接时，本地内容与现存云端按首次连接流程选择，不自动续传停止期间的变更。

### 撤销旧设备并重新连接

持有正确口令时可选择“撤销全部旧设备并重新连接”，独立确认会使其他设备停止同步。该操作不删除配置、不修改口令、不消耗邀请码，也不影响管理员会话。服务端原子撤销该空间全部旧设备令牌及相关签发回执、递增设备授权代次并签发当前设备新令牌；空间内容代次与配置 revision 保持不变，不能把重新连接当作恢复或覆盖配置。

操作使用稳定请求 ID，确认后的重试必须复用该 ID；成功结果保留短期加密回执，避免响应丢失后反复撤销刚签发的连接。签发、重置及其回执均绑定当前设备授权代次，后续撤销后旧回执不能重新返回可用凭据。其他设备收到已撤销状态后保留本地配置、断开并要求用户主动输入口令，禁止后台自动恢复连接。当前设备先协调本地与云端版本，再恢复同步。过期令牌采用相同主动重连入口，正常新增设备不要求撤销旧设备。

### 自动同步及时效

- 本地有效修改后合并 500 毫秒触发上传，持续操作最长等待 2 秒发起一次；同浏览器仅一个上传在途，后续修改合并到下一次。
- 首次打开、标签页恢复可见、网络恢复时立即检查云端版本；可见页面每 30 秒检查，隐藏页面停止轮询。
- 无待上传修改时直接采用较新的云端配置并持久化；有本地修改时先检查版本，再提交或进入冲突状态。
- 页面关闭前已保存本地的修改，下次打开继续同步；不承诺关闭瞬间的网络请求一定到达。其他设备能读取的最新状态以已成功上传版本为界。
- 失败指数退避，最长 5 分钟，恢复联网允许立即重试。无长连接和常驻推送。

### 冲突与多标签页

- 云端配置带 schemaVersion、空间代次和单调 revision；更新携带 baseRevision，服务端事务比较并递增，冲突返回 409。
- 每次普通配置提交使用稳定随机 operationId，待提交内容及其 ID 一起保存本地，网络重试和重启后续传复用同一 ID。服务端在同一事务内保存配置、版本及成功回执；先验证当前身份、空间代次和状态，再判断已提交操作，最后检查基线版本。相同 ID 和相同内容返回原提交版本，不重复写入；相同 ID 携带不同内容明确拒绝。客户端收到原成功结果后仍检查最新云端版本，不把旧回执当作当前完整配置覆盖本地。
- 所有云端读取结果、上传确认和冲突选择落盘均检查连接代次及请求发起时的本地修订号。读取期间产生新修改时，保留新本地内容并重新协调版本，禁止用迟到读取覆盖；上传确认只确认实际发送的修订号，不能清除随后产生的待上传修改。
- 多标签页共享 IndexedDB，通过浏览器锁协调保存和上传，用 BroadcastChannel 通知更新；不支持该锁的平台采用等效的 IndexedDB 事务协调。竞争写入必须检查本地修订号。
- 收到其他标签页变更时，无草稿直接刷新；有未确认编辑保留草稿并提示，不覆盖输入。
- 首版按整份配置解决冲突，不自动逐字段合并。保留两个候选，用户选择云端或本地，覆盖前再次校验 revision。允许先导出候选再选择。

### 停止与删除

- 停止同步在共享 IndexedDB 事务中递增连接代次、标记未连接并清除口令、派生凭据、设备令牌和待同步任务，随后通知全部标签页取消调度；操作完成以事务提交为准。保留本地配置和不含凭据的连接代次。撤销当前设备令牌所需值仅临时保留内存，尽力向服务端撤销，离线撤销失败不妨碍本地断开。
- 连接保存、任务入队和任何响应落盘均在写事务内比较预期连接代次。首次连接及重新连接先取得当前代次，停止、切换和删除使旧代次失效；迟到的连接请求或旧标签页不能把凭据写回。BroadcastChannel 只用于通知，不承担并发正确性。
- 每次请求绑定本地连接代次，停止或切换后忽略旧请求响应。界面说明已到达服务端的上传可能完成，停止不回滚该次写入。
- 删除云端要求在线、明确确认并重新输入口令。删除期间暂停本浏览器上传。成功删除配置、撤销全部设备令牌，再按相同本地事务规则断开并递增连接代次；失败保留数据和连接并显示错误。网络结果不确定时先查询原空间代次是否仍存在，不自动重建或宣称删除成功。
- 删除与上传在服务端串行事务中比较空间代次；删除先完成时旧上传必须失败。旧设备收到失效响应后清除连接，保留本地配置，不自动重建。
- 同口令可在用户明确创建后生成新空间，使用新代次和新令牌；旧设备令牌无法访问新空间。服务端不提供上传时自动创建能力。

## 6. 管理员与模块权限

### 独立管理员认证

沿用现有管理员密码登录入口和会话保护。管理员密码至少 12 个字符，满足大写、小写、数字、符号中的至少三类。升级时撤销全部旧管理会话；后续每次验证密码时检查复杂度。合规密码签发正常会话，旧弱密码只签发有效期 10 分钟的独立改密凭据，不签发正常会话。改密凭据仅可调用改密与退出接口，不可访问收藏、私人模块或其他管理功能，也不自动续期；改密成功后撤销该凭据并建立正常会话。匿名首页和普通同步不受影响。

普通管理及私人读取接口取消 `x-admin-password` 直接验证后放行的兼容路径，只接受正常管理员会话。密码验证入口仍可接收登录密码，但不能凭该请求头直接执行业务操作。改密沿用已有凭据重加密流程，失败不得显示成功；升级强制改密须验证 WebDAV、监控及订阅凭据的实际可用性。

管理员会话使用独立 HttpOnly cookie；普通同步用独立设备凭据访问专用接口，绝不提升到管理员。拒绝将同步口令用于管理接口，以及通过同步配置指定私人数据路径。管理写请求保留来源校验并补齐 CSRF 防护。

管理界面明确区分“管理员个人首页”和“站点默认首页”。普通个人设置只写普通本地及云端配置；管理员个人保存只写管理员配置；默认首页发布只写公开模板。三者的版本、草稿、队列和请求标识独立，不复用隐式身份判断决定写入目标。

### 管理员自动同步与身份切换

- 管理员导航及引擎、模块配置使用服务端持久化数据，不创建普通云端空间，不消耗邀请码、普通设备连接数和普通空间配额。现有备忘录、监控、时间线继续使用原有私人接口和业务语义，配置同步不复制运行时指标或重新触发采集。
- 管理员导航结构编辑保留现有草稿、保存和取消流程；点击保存后写入服务端，成功才显示“已保存并同步”。即时设置沿用现有即时保存交互，连续操作合并上传。其他设备打开、恢复可见或恢复网络时立即读取最新配置，可见时每 30 秒检查配置版本。个人导航保存和即时设置不产生公开效果；默认首页发布前单独预览并说明对首次访问及重置的影响。
- 管理员个人导航及引擎、模块配置、默认首页模板各自维护可持久验证的版本，更新携带基线版本，服务端串行检查与写入，成功后才更新版本。多设备同时修改同一配置域返回 409，保留本设备草稿和服务端版本让用户选择，不静默覆盖；不同配置域的修改不得互相抹除。私人模块数据的更新继续通过各自业务接口。管理员配置保存和默认首页发布也使用稳定 operationId 与成功回执，和版本、配置在同一持久化提交中生效；已提交但响应丢失时返回原成功结果，不制造虚假冲突。普通及管理员回执保留 24 小时并清理；超过窗口先读取当前版本核对结果，不盲目重新提交或直接覆盖，无法确认时保留草稿进入明确的版本协调流程。
- 管理员有草稿时，其他设备更新只提示“其他设备已更新”，不覆盖当前输入。管理员写入失败保留草稿供重试或取消，不自动写入普通本地配置，也不使用普通同步令牌重试。首版管理员离线时可保留当前页面内草稿，但不支持跨关闭页面持久离线编辑；刷新或关闭前提示未保存风险。
- 登录前的普通有效修改先提交本地事务；未完成的普通表单要求保存或放弃，取消则不开始登录。发起登录前暂停普通同步、递增独立的首页上下文代次并取消旧调度；登录失败回到普通上下文协调版本，成功则加载管理员数据。普通连接代次保持不变，暂停不等于停止或清除凭据。
- 主动退出管理员时，有待保存请求先等待结果；有草稿先选择保存、放弃或取消退出。退出成功后清理管理员配置、模块、索引及内存草稿，恢复之前的普通本地配置。之前有口令连接则先协调版本再恢复普通同步，保留登录前未上传修改，禁止直接覆盖云端。没有普通副本时获取当前公开默认首页建立副本。
- 管理员会话明确过期或撤销时，立即停止管理员请求并隐藏私人数据。未保存导航草稿暂留当前标签页内存，提供重新登录后按版本恢复或明确放弃；草稿未处理前阻止普通编辑和普通上传，避免错误归属。不能重新登录时允许放弃后恢复普通视图，不将管理员草稿导出为普通配置。网络错误不冒充会话过期。
- 管理员 cookie 为同站标签页共享。登录、退出和失效通过 BroadcastChannel 通知所有标签页；每个标签页恢复可见时复核会话，服务端始终即时校验。其他标签页有草稿时保留在其原上下文并提示处理，不能自动迁入新身份。身份切换所有响应落盘和界面应用都检查首页上下文代次；旧普通响应不能覆盖管理员界面，旧管理响应不能在退出后重挂载私人模块。
- 仅本地首页上下文切换不会撤销普通云端凭据。管理员退出只撤销当前管理员会话，其他设备管理员会话保持；改密和安全操作要求全量撤销时按已有安全语义执行。普通云端空间被别处删除或禁用时，在恢复普通上下文后按该空间状态处理，不影响管理员配置。

### 模块开发分类

每个模块开发时声明 `admin` 或 `public`，并声明可同步配置白名单及校验规则。缺少声明拒绝注册。管理员模块不能通过运行时设置变成公开模块。

初始分类：备忘录、主机监控、Special Line 为管理员模块；微博热搜为公开模块。文本分享保留现有匿名独立功能，不强行包装成模块。

公开模块默认不对外开放，管理员逐个配置。普通上下文的实际启用条件为公开分类、管理员已开放、个人已启用同时成立；管理员上下文按管理员模块配置启用公开及私人模块，不受对外开放开关限制。脚本加载、接口访问和后台执行分别校验，隐藏界面不能替代权限。

关闭公开模块后，普通设备下一次策略检查即卸载并停止请求，服务端立即拒绝访问。保留普通个人偏好以便重新开放恢复。管理员仍可在管理员首页使用，公共接口关闭不妨碍独立管理读取接口。

政策离线时使用最近一次已知结果，网络恢复立即校验；服务器仍即时执行最新权限。新模块没有已知授权时不加载。

## 7. 服务端结构、接口与资源

保持单 Node.js 服务和现有 SQLite。追加迁移存放同步空间、revision、代次、设备令牌和邀请；不改既有迁移，不将管理员私人数据迁成多租户。

接口职责分离：

| 接口组 | 职责与鉴权 |
| --- | --- |
| 公开首页及策略 | 只读取已发布默认模板及获准模块，不读取管理员个人导航、引擎或收藏，不因管理员 cookie 改变内容 |
| 默认首页管理 | 管理员会话独立读取、校验及带版本发布模板，不修改管理员个人配置 |
| 同步连接 | 口令派生凭据查询、创建、连接；创建额外验证邀请码 |
| 同步配置 | 设备令牌鉴权，读取、带版本更新、断开与删除 |
| 管理员首页配置及版本 | 正常管理员会话直接读写与版本检查，不需要同步口令，不返回给公开接口 |
| 站点管理与私人模块 | 仅管理员会话，不接受同步令牌 |
| 公开模块数据与文本分享 | 公开策略及独立限流，沿用分享现有协议 |

同步口令及可访问空间的标识不放 URL、分析事件或日志。浏览器使用 Web Crypto 对带版本和用途隔离的口令输入派生连接证明；服务端存储验证或定位所需值，不存明文口令。设备令牌使用安全随机值，数据库仅保存哈希。不设置每空间设备数量上限，新增设备无需挤占固定名额；设备数量增加仍共享空间的读写额度。令牌连续 90 天无成功鉴权后失效，正常读写滑动续期。浏览器重启优先复用已有令牌，不重新签发；连接请求带稳定随机请求 ID，同一次连接的网络重试幂等返回同一结果。签发与回执记录在事务中完成，同 ID 重试不得重复创建记录。每日及签发前清理过期、已撤销记录，撤销后所有签发回执同步失效；签发回执只保留 24 小时，返回材料使用服务端私有密钥加密，不保存明文令牌。已过回执期且本地仍未完成连接时需要用户主动重新连接，不无限重试。连接接口继续按 IP 限流，并对正确口令验证后的每空间签发限制为 30 次/分钟，429 明确提示等待，不回退到创建新空间。

数据库或网页脚本被运营者访问的信任边界必须说明，首版不宣称端到端加密，也不承诺弱口令抗离线猜测。

普通配置服务端执行严格 schema、URL 协议、长度、数量及请求体校验。接受个人搜索引擎定义、排序及当前选择，拒绝管理员字段、收藏库、私人模块和凭据。引擎复用既有搜索 URL 模板约定，客户端与服务端均校验 HTTP/HTTPS 协议、模板格式和唯一 ID，禁止脚本协议；关键词按模板约定编码。服务端只保存配置，不代用户执行搜索或抓取引擎地址。配置仅存链接与参数，不抓取用户导航目标或上传图片。

首版资源默认值：每空间最多 1 MiB JSON、2,000 个导航链接、100 个分类、50 个搜索引擎；最多 1,000 个空间、云端有效配置总量最多 1 GiB。达到额度拒绝新增或增量写入，已有读取、删除和缩减写入保留。实际 SQLite 文件可因日志和索引更大，需要独立磁盘检查。

邀请码随机生成，默认单次使用、48 小时有效，管理员可撤销。暂停新建仅影响新空间，已有空间继续同步；提供独立总同步开关。管理员空间列表仅展示不具备访问能力的内部标识、体积、时间及状态，支持禁用、删除，不提供正文或口令入口。空间禁用返回明确的停用状态，客户端停止自动重试、保留本地配置和连接，用户可主动断开或在重新启用后手动重试；空间删除及令牌过期返回不同错误，前者断开，后者要求重新输入口令，不在后台自动重连。总同步关闭返回暂停状态，客户端暂停自动同步，按 5 分钟间隔检查公开策略或由用户手动重试，重新开放后恢复版本协调。

正常每空间上传上限 120 次/分钟、读取上限 240 次/分钟，连接或口令尝试每 IP 30 次/分钟，超过返回 429 和 Retry-After；公共榜单缓存并合并刷新。首版不对普通空间运行时间线、翻译、主机采集或 WebDAV，因此此前 150 个订阅来源及 90 台监控目标的压测目标作废。

## 8. 管理员 WebDAV 备份调整

新备份包含管理员收藏夹及隐私标签、备忘录正文和状态、主机监控配置、Special Line 来源和事件及归档收藏状态，以及对应私人模块开关和布局。

管理员自动跨设备同步与 WebDAV 分工独立：导航及引擎由服务端配置同步，WebDAV 范围维持本节约定。

不包含管理员个人导航、独立默认首页模板、搜索引擎定义、普通本地配置、普通云端空间、邀请码、设备令牌、管理员密码和会话、监控缓存。

沿用现有凭据不明文导出原则，跨安装不能复用的凭据不加入备份；主机及订阅恢复后缺少凭据时明确显示待重新部署或授权，不显示已恢复可用。

新增备忘录备份，版本化备份清单，按实际备份内容计算校验和。恢复前说明包含和跳过项目；旧配置备份可以读取，但不再恢复首页和搜索引擎，明确提示不在新版恢复范围。恢复失败保持原数据，恢复和自动备份互斥，避免上传半套快照。

恢复期间与正常管理员配置写入共用实例内写入协调锁，受影响域暂时拒绝新写入并提示恢复中。开始替换前暂停并等待受影响私人模块的在途任务结束，避免旧任务在恢复后继续写入。恢复前校验全部选中内容并建立本地恢复前快照，跨 JSON 与 SQLite 的替换具备可重试完成或完整回滚的恢复记录；进程中断后先完成恢复或回滚，再开放服务，不向外提供半套结果。

成功恢复必须递增所有受影响配置域的版本，并使旧基线和恢复前未决写入失效；配置同步设备下一次读取看到新版本，有草稿则提示冲突，不能把旧配置静默写回。恢复失败且回滚成功保持恢复前配置和版本；回滚失败则暂停受影响服务并明确提示。恢复完成后重新装配模块及缓存，再恢复后台任务。

管理员公开及私人模块共用展示布局，但 WebDAV 仅备份和恢复私人模块的开关、布局项和业务设置。导出按模块分类白名单过滤，恢复时按稳定模块 ID 合并私人项，保留当前公开模块项及相对顺序，不整份覆盖管理员模块配置。未知模块跳过并报告，空间不足时沿用既有布局回退规则，不丢弃公开模块配置。收藏和备忘录等内容的恢复同样不得改变导航、引擎或默认模板。

整机运维快照与 WebDAV 范围独立，升级快照仍需包含管理员配置、凭据和数据库，不能用新个人备份替代回滚快照。

## 9. 升级与兼容

- 升级时将原管理员完整配置保留为管理员个人配置，沿用旧版公开过滤规则生成独立默认模板的一次性初始副本，再以新版公开 schema 校验；剔除收藏、私人模块、凭据及非公开字段。新安装默认模板和管理员个人导航均从出厂默认值独立初始化。初始化后两者无自动关联，管理员修改个人配置不更新默认模板。迁移失败不发布未校验模板，快照保留全部原数据。收藏、私人模块及凭据保留原归属。收藏库访问范围改为管理员专用，保留条目的既有隐私属性供管理和备份使用。复查全部原公开及软鉴权接口，撤销匿名收藏读取；管理员收藏使用独立鉴权接口并禁止缓存，不能让管理员 cookie 改变可缓存的公开响应。
- 已有浏览器仅迁移确认属于公开偏好的旧数据，不能把曾缓存的管理员完整配置自动上传。旧后台或旧前端版本写入不兼容时返回明确刷新提示。
- 同步采用独立 schemaVersion；更高未知版本拒绝替换本地，提供导出与升级提示。API 和本地存储迁移可重试，不静默回退到空配置。
- IndexedDB 和 Service Worker 分开升级，激活新静态缓存不能删除个人导航及引擎配置。升级时只清除旧收藏响应、收藏索引及失效的公开收藏缓存，无法联网确认管理员身份时不展示旧收藏数据。匿名收藏检索退出属于明确兼容性变化，发布说明中说明；个人导航链接和网页搜索不受影响。变更公开过滤、搜索或分享行为须有定向回归。
- 升级前生成可恢复快照，数据库只追加迁移，失败不启动不完整服务。回退旧版使用完整快照，禁止旧程序直接操作已升级数据库。

## 10. 验证与完成标准

主测试入口为真实 HTTP 服务、临时安装及 SQLite，加真实浏览器验证持久化和多标签页。复用现有公开投影、会话、分享、模块、备份及时间线真实服务测试方法。只替换第三方网络上游；权限、持久化和版本竞争必须执行真实实现。

必须覆盖：

1. 无本地数据首次访问；离线回访；刷新及浏览器重启；管理员默认更新不覆盖个人配置；本地存储失败不假报成功。
2. 两个浏览器分别编辑同一空间，自动同步、打开及恢复可见立即刷新、同时写入返回冲突，迟到响应不覆盖新修改。普通上传、管理员保存及默认模板发布均覆盖提交成功但响应丢失、页面重启后重试：相同 operationId 不重复写入或产生虚假冲突，内容不同时拒绝；超出回执保留期按当前版本协调。
3. 本地未连接、创建、连接已有空间、邀请码过期及复用、竞争创建、限流与超额。
4. 停止同步跨标签页生效，删除本地凭据，离线修改保留，刷新后不恢复同步；通过延迟连接响应、排队的 IndexedDB 写事务及旧标签页任务构造竞争，证明停止后凭据无法复活；迟到读取不覆盖请求发出后的本地修改。
5. 云端删除与上传竞争、旧设备离线后重新上线、同口令新建，证明旧令牌不能恢复或访问新空间。
6. 重置及导入在同步开启和关闭时的差异，重置获取失败不改原数据，冲突候选和恢复副本可导出。
7. 两台干净设备仅登录管理员即可共享个人导航、引擎和模块布局，无需同步口令；个人保存不影响公开默认模板。默认模板独立编辑、预览和发布，仅影响新本地副本及主动重置，不覆盖管理员个人导航或已有普通配置。验证三类配置请求目标、草稿及版本独立，模板并发发布返回冲突，公开响应不因管理员登录暴露个人配置。
8. 普通空间连接后登录管理员，原配置及待上传修改保留且停止调度；管理员修改不写普通空间。退出恢复普通配置并协调版本，其他管理员设备保持登录。验证多标签页登录退出、会话过期、网络失败、延迟响应和未保存草稿处理，无配置串写或私人模块残留。
9. 验证个人引擎新增、编辑、排序、切换、删除回退、重置、导入导出及跨设备同步；合法自定义引擎可保存，非法协议、模板、重复 ID、空列表和数量超限被拒绝。伪造管理员字段、收藏及私人模块，直接调用私人接口均被拒绝；公开接口不能因管理会话返回私人数据。
10. 匿名及普通空间均无收藏检索入口，直接请求原非私密和私密收藏、搜索、分类、计数及导出全部被拒绝；普通同步令牌不能访问收藏。验证管理员登录后可以检索，退出、多标签页及离线回访不会残留收藏响应、索引或内容。
11. 升级后旧管理会话失效；弱密码只获得限时改密凭据；以旧 cookie、管理密码请求头和改密凭据直接访问私人及管理接口均失败。改密完成后正常会话可用，凭据重加密及私人功能正常；凭据重加密失败不假报成功。
12. 模块开放、关闭、离线及重新开放，公开缓存不暴露私人模块，服务端立即执行策略。
13. WebDAV 新旧备份、备忘录、隐私收藏、凭据缺失提示、部分失败及进程中断回滚，默认首页和云空间不被恢复覆盖。另一管理员设备保存与恢复竞争时，证明锁、版本更新及旧基线拒绝生效；私人模块恢复不覆盖公开模块设置和布局，在途私人任务不能在恢复后写回旧数据。
14. 旧浏览器、旧接口、本地 schema 升级、Service Worker 更新及整机回滚，无数据泄露或丢失。
15. 设备连接同请求重试不增加令牌数，浏览器重启复用令牌；至少连接 20 个独立设备，证明无 10 设备或其他固定数量上限。验证 90 天失效、每日清理、签发限流及并发幂等；撤销全部旧设备并重新连接时配置保持，响应丢失重试不反复撤销，旧令牌和旧签发回执无法恢复权限。验证空间停用、删除、令牌过期、设备撤销和总同步暂停的不同处理，无无限重连。

容量验证以 2 核 2 GB 为目标，使用 30 个空间、每空间两台可见设备运行 24 小时，包含编辑突发、冲突、断网重连及管理员私人模块同时运行。另验证空间总量和 1 MiB 配置边界。记录 CPU、RSS、数据库及 WAL 体积、请求 P95、同步延迟、失败重试和私人模块影响，不将仅空闲轮询测试当完整容量结论。

时效验收使用无故障、单次请求往返不超过 200 毫秒的合成网络，目标配置在服务端处理时间不超过 100 毫秒，设备无冲突及待上传修改。500 毫秒合并后开始上传，持续编辑按 2 秒上限触发。接收设备打开、恢复可见或恢复网络后立即检查，以触发检查起 2 秒内展示检查时最新已提交配置为目标；持续可见设备按 30 秒轮询，以服务端提交起 32 秒内更新为目标。两个指标分别计时与记录，普通口令设备和管理员会话设备均须独立验收；管理员结构编辑从点击保存并成功提交起计时，不能要求未保存草稿传播。测试固定轮询相位覆盖最坏等待。存在冲突、限流或故障时展示实际状态，不计入正常时效样本，但必须单列恢复结果。实际公网延迟单独测量，不承诺绝对实时或断网同步。

运行相关定向测试及 `node --test tests/*.test.js`，适用语法检查和 `git diff --check`。测试报告区分 HTTP、浏览器、压测和真实部署结果。完成后再更新已实现架构，发布使用仓库既有脚本。
