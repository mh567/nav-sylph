# 收藏隐私模式设计

## 背景

收藏夹中部分书签较为敏感，搜索框输入 `/` 后默认展示的书签中可能包含不希望被看到的内容。需要一种机制让用户主动控制敏感书签的可见性。

## 需求

1. 书签可标记为「隐私保护」
2. `/` 搜索仅展示普通书签，`//` 搜索展示全量书签（含隐私）
3. `//` 仅在管理员已登录且隐私模式开关开启时生效，否则等同 `/`
4. 后台管理面板增加隐私模式开关（持久化）和登出按钮
5. 登出后隐私搜索失效，无论开关状态
6. 导入导出不受影响，目录结构完整保留

## 数据结构

### favorites.json - 书签增加 private 字段

```json
{
  "id": "fav_xxx",
  "title": "敏感站点",
  "url": "https://example.com",
  "private": true
}
```

- 缺省或 `false` 表示普通书签
- 导入的书签默认 `private: false`
- 导出时忽略该字段，目录结构完整输出

### config.json - 增加隐私模式开关

```json
{
  "privacyMode": false
}
```

- 通过现有 `/api/config` 接口读写，需管理员密码

## 交互逻辑

### 搜索行为

- `/` 触发收藏搜索：仅展示 `private !== true` 的书签
- `//` 触发隐私搜索：需同时满足已登录 + `privacyMode` 为 `true`，展示全量书签，隐私书签带小锁图标
- 条件不满足时 `//` 等同于 `/`，无任何提示

### 后台管理面板

- 新增「隐私模式」toggle 开关，状态持久化到服务端 config.json
- 新增「登出」按钮，退出登录状态，前端清除密码，隐私搜索失效
- 分类树视图不受隐私模式影响，始终展示全部书签

### 收藏创建/编辑

- 表单中增加「隐私保护」复选框
- 编辑时回显当前状态

## 兼容性

- `private` 字段为 Nav Sylph 自有扩展，不影响 Netscape bookmark HTML 导入导出格式
- 向后兼容：无 `private` 字段的旧书签视为普通书签
- config 迁移：无 `privacyMode` 字段时默认 `false`
