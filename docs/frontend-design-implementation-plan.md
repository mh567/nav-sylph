# 前台设计修改方案

## 视觉与布局

首页维持紧凑的多列导航，不扩大菜单卡片。书签统一显示文字，取消 favicon 请求。页面使用暖灰背景、低饱和陶土色强调、细边框和柔和高光。搜索框以半透明材质、内缘高光与轻微下沉的聚焦状态建立层次。浅色和深色均保留可辨识的悬停反馈；搜索框本体的跟随光只做弱提示。

## 操作映射

搜索框左侧提供“网页/收藏”模式切换按钮，搜索引擎另设独立文字按钮，收藏模式隐藏引擎按钮。保留输入 `/`、`//` 和分享触发符的原有语义。提交按钮、管理和帮助入口统一使用文字。书签、引擎选项、收藏结果、弹窗按钮覆盖悬停、键盘聚焦、按下及禁用状态，按下状态使用内阴影模拟凹陷。保存结果继续沿用现有状态文字与提示。

## 性能与适配

首页不请求书签站点图标。鼠标位置光感仅用于搜索框和当前悬停卡片，按需更新，触屏设备停用悬停特效。支持减少动态效果、减少透明效果及无毛玻璃浏览器。保持现有按需加载收藏和配置机制。

## 检查点

检查网页搜索、引擎切换、收藏按钮及 `/` 检索、`//` 隐私检索、分享输入、书签跳转、管理保存状态。分别核对桌面和窄屏的布局以及明暗模式。浏览器视觉验收需要可访问页面环境，本轮先完成可执行的静态检查与代码级关键路径检查。
