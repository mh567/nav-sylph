## 范围与验证入口

导航及引擎沿用独立 SQLite 管理员域；模块补充版本及幂等协议；浏览器补充自动协调、草稿及身份生命周期。无新增依赖、普通空间、口令或邀请码。真实 HTTP 使用临时安装、实际会话、SQLite 与 JSON 文件；浏览器使用本机 Chrome 的隔离上下文及标签页，仅合成数据。
