# Sylph 与 Pabu 产品边界

确认日期：2026-11-08。用户已授权实际拆分，并明确当前无用户，不需要空间或用户数据迁移。

## Sylph

自部署的个人数字工作台。集中导航、私人收藏、临时文本分享、备忘待办、主机监控、订阅时间线和备份。管理员登录后在多台设备使用同一份个人配置。

保留访客本地导航、显式发布的站点默认首页与公开模块策略。它们属于可公开使用的辅助入口，不提供普通用户云端空间。口令同步的前端、服务端与管理功能已删除。

## Pabu

同级独立项目 `../pabu`，面向公众的导航管理、口令同步与临时文本分享工具。独立版本、配置、数据与发布目的地；不继承 Sylph 的私人配置或远端。

| 能力 | Sylph | Pabu |
| --- | --- | --- |
| 导航、搜索引擎、本地保存与导入导出 | 保留 | 保留 |
| 口令空间、设备连接与空间治理 | 删除 | 保留 |
| 临时加密文本分享 | 保留 | 保留 |
| 私人收藏库、备忘待办 | 保留 | 移除 |
| 主机监控、采集程序、私人订阅时间线 | 保留 | 移除 |
| WebDAV 私人数据备份恢复 | 保留 | 移除 |
| 管理员认证与默认首页发布 | 保留 | 保留必要站点管理 |

Pabu 这轮沿用邀请码创建空间，未增加自助开放注册。同步配置服务端可读，不能宣传端到端加密；文本分享的加密协议单独描述。

## 版本与数据边界

Sylph 候选版本为 2.3.0，未发布。数据库按原约定追加清理台阶，首次启动会删除口令空间相关表，不提供迁移或恢复原同步服务。私人工作台数据继续使用原存储。

本次没有修改当前目录里的实际私人配置、会话库或书签数据。Pabu 从 Git 跟踪源码复制，未复制这些数据。

## 后续方向

Sylph 后续可验证资料关联、工作进展与 AI 上下文交接。Passkey、多因素认证、敏感操作再次验证及独立智能体授权均属于后续设计，本轮没有新增这些能力。

Pabu 优先完善公众用户的导航编辑、跨设备可靠性、文本分享及服务治理。两边独立维护，暂不抽取公共框架，也不引入新的模型依赖。
