提案改了什么

只动视觉层，结构、间距节奏、限高滚动与 44px 热区保持不变。切换上方「当前 / 提案」与行状态即可对照。

  • 页签分段控件改为「下沉槽 + 抬起选中块」，按压下沉；与搜索栏三按钮同一套控制语言。
